# Military Symbols Quiz

A Flutter application that provides quizzes on military symbols using FlutterPerformanceHistorian and FlutterMilSymbol packages.

## Features

- **Interactive Military Symbol Quizzes**: Test your knowledge of NATO military symbols
- **Multiple Difficulty Levels**: Beginner, Intermediate, and Advanced quizzes
- **Performance Analytics**: Track your progress and improvement over time
- **Real-time Feedback**: Get instant feedback on your answers with explanations
- **Symbol Recognition**: Learn to identify different military unit types and affiliations

## Quiz Types

1. **Basic Military Symbols**: Introduction to fundamental military symbols
2. **Symbol Types Recognition**: Identify friendly, hostile, neutral, and unknown symbols
3. **Advanced Symbols Quiz**: Complex military symbols and NATO APP-6 codes

## Getting Started

This application is built with Flutter. To run the application:

1. Ensure you have Flutter installed on your system
2. Clone this repository
3. Run `flutter pub get` to install dependencies
4. Run `flutter run` to start the application

## Dependencies

- **FlutterPerformanceHistorian**: Performance monitoring and analytics
- **FlutterMilSymbol**: Military symbol rendering and manipulation
- **Flutter SDK**: 3.10.0 or higher

## Usage

1. Select a quiz from the home screen
2. Answer questions by tapping on the correct option
3. View explanations after each question
4. Check your performance analytics to track improvement
5. Retake quizzes to improve your scores

## Educational Value

This application helps military personnel, students, and enthusiasts learn to:
- Recognize NATO military symbols
- Understand unit types and affiliations
- Improve tactical awareness
- Practice symbol identification under time pressure

## Performance Tracking

The app tracks various metrics including:
- Quiz completion rates
- Answer accuracy
- Response times
- Progress over time
- Areas for improvement
